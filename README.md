#Portfolio project in Semester 3, to help me find an internship in Semester 4 and present my work.#

The project focuses on creating a personal portfolio website for an upcoming internship search in semester 5. It presents previous projects, skills, and personal interests, with a focus on graphic design and other creative fields. Alongside work from previous semesters, it also includes personal projects such as photography and digital art to show a wider range of skills and creative thinking.

The website has a colourful and creative visual identity, with the design itself reflecting the personality and abilities of its owner. The design is a corkboard covered with notes, where each note contains different information about me, my projects, and experience. This approach also allows for custom-made visual assets, graphics, and different colour combinations.

The main target audience consists of recruiters, HR employees, and creative directors from companies offering design-related internships.Its layout focuses mainly on PC screens, using a horizontal format that adapts to different screen sizes.
